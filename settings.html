快速开始

使用步骤

  1. 启用插件

    在设置页面勾选"启用防盗插件"选项。

  2. 导入角色卡

    导入带有防盗保护的角色卡文件（PNG 格式）。

  3. 输入密码

    如果角色卡被锁定，会自动弹出密码输入对话框。

  4. 开始使用

    输入正确的密码后，即可正常使用角色卡。

常见问题

提示"请安装防盗插件"？

说明插件未正确加载。请检查：

  • 插件是否安装在 public/scripts/extensions/third-party/antitheft/ 目录
  • 是否已重启 SillyTavern
  • 浏览器控制台是否有错误信息

密码验证失败？

可能的原因：

  • 密码输入错误，请向角色卡作者确认正确密码
  • 网络连接问题，无法访问验证服务器
  • 服务器地址配置错误

如何查看调试信息？

启用调试模式后，按 F12 打开浏览器开发者工具，切换到"控制台"标签页查看详细日志。

如何为自己的角色卡添加防盗保护？

请访问 GitHub 仓库 查看完整的创作者指南。

开发者 API

插件提供全局 API 对象 window.AntiTheftPlugin，包含以下方法：

verifyPassword(cardId, password, serverUrl)

验证角色卡密码。返回包含验证结果的 Promise。

checkPasswordVersion(cardId, serverUrl)

检查服务器上的密码版本号。返回版本号或 -1。

checkVersion()

获取插件版本信息。返回包含名称、版本号和安装状态的对象。
