角色卡防盗
版本 1.0.0
启用后，插件将自动检测加密角色卡并提供密码验证功能。
启用后，将在浏览器控制台输出详细的调试信息。
可选配置。如果角色卡未指定服务器地址，将使用此默认值。留空则使用角色卡中的配置。

使用说明

  1. 确保插件已启用
  2. 导入加密的角色卡
  3. 如果角色卡被锁定，会自动弹出密码输入对话框
  4. 输入作者提供的密码即可解锁

常见问题

  • 提示"请安装防盗插件"？
    说明插件未正确加载，请检查插件是否安装在正确的位置。
  • 密码验证失败？
    请检查网络连接和密码是否正确，或联系角色卡作者。
  • 如何查看调试信息？
    启用调试模式后，按 F12 打开浏览器控制台查看详细日志。

API 文档

插件提供以下全局 API（通过 window.AntiTheftPlugin 访问）：

  • verifyPassword(cardId, password, serverUrl) - 验证密码
  • checkPasswordVersion(cardId, serverUrl) - 检查密码版本
  • checkVersion() - 检查插件版本
